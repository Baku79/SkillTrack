#  Overview

SkillTrack is a full-stack AI-powered platform developed for **Smart India Hackathon (SIH) 2026** to solve the challenge of tracking long-term employment outcomes of trainees after completing skill development programs.

The platform enables government agencies, training institutes, employers, and candidates to collaborate through a secure system that monitors placements, employment retention, wage progression, self-employment, apprenticeships, and skill gaps.

---

#  Problem Statement

Current skilling programs collect data such as:

- Student Enrollment
- Attendance
- Assessments
- Certifications

However, reliable information about:

- Employment Status
- Job Retention
- Wage Progression
- Self-Employment
- Apprenticeships
- Skill Gaps
- Program Effectiveness

is often missing.

Our platform solves this problem through AI-powered analytics and longitudinal outcome tracking.

---

# Solution

SkillTrack provides a centralized platform where:

-  Government agencies monitor programme outcomes.
-  Training Institutes manage candidates and placements.
-  Candidates maintain their digital Skill Passport.
-  Employers recruit verified skilled candidates.

The platform continuously tracks employment outcomes and provides data-driven insights for better policymaking.

#  Installation

Clone Repository

```bash
git clone https://github.com/yourusername/SkillTrack.git
```

Go into project

```bash
cd SkillTrack
```

Install Frontend

```bash
cd client
npm install
```

Install Backend

```bash
cd ../server
npm install
```

Run Backend

```bash
npm run dev
```

Run Frontend

```bash
cd ../client
npm run dev
```

Open Browser

```
http://localhost:5173
```
